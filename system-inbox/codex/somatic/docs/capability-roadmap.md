# Capability Roadmap

- Offline workflow fixture validation.
- Mock provider metadata loading.
- Mock run artifact writing.
- Evidence Bus dataclass contracts.

- Research engines lane.
- Sensors lane.
- Safety lane.

- Basic installed console script path.
- Mock provider registry.
- Local evidence index.
- Local replay of prior run artifacts.
- Optional CLI polish with `typer` and `rich`.

- Real agent frameworks.
- Biomodel execution.
- WiFi CSI planning metadata. Live WiFi CSI capture remains disabled and future-only.
- Video, thermal, audio, and wearable integrations.
- Cloud or wet-lab integration.
- Fabric transport and signature verification runtime.
