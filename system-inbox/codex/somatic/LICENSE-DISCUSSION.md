# License Discussion

Somatic is intended to be an open scientific discovery harness, but the final license has not been selected.

## Goals

- Keep the core harness usable for public research.
- Allow provider adapters to support open, commercial, academic, and local-first backends.
- Preserve clear attribution for datasets, model weights, workflow packs, reports, and plugin packs.
- Avoid accidentally relicensing third-party scientific assets.
- Make license gates explicit in the future content fabric.

## Candidate Directions

- Permissive core license such as Apache-2.0 or MIT for framework code.
- Separate licenses for documentation, examples, datasets, models, and workflow packs.
- Stronger review for code packs that run executable plugin or adapter code.
- Manifest-level license metadata in `pack.json` for fabric-distributed content.

## Phase 0 Position

No final license is granted in this skeleton. A future phase should add a root `LICENSE` file and update this document with the decision record.
