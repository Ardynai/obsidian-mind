# Table Evidence Fixtures

These CSV files are deterministic local fixtures for the Phase 5D Finch
toolbelt. They are sandbox inputs only. They are not real clinical, wetlab, or
scientific measurements.

- `simple-lab-results.csv`: small grouped numeric table.
- `dose-response.csv`: monotonic mock dose/response table.
- `missing-values.csv`: missing-value profiling fixture.
- `non-numeric-table.csv`: categorical-only fixture.
